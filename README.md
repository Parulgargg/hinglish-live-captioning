# Hinglish Live Captioning

This project provides:

- Speech-to-Text using Whisper
- English to Hinglish Translation
- Meeting Summarization
- Live Caption Generation

## Files

- run_everything.py
- run_pipeline.py
- hinglish_translate.py
- summarizer.py

## Technologies Used

- Whisper
- WhisperX
- Transformers
- Helsinki-NLP Translation
- BART Summarization
